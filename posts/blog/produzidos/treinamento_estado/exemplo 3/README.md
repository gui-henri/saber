# Gerenciamento de estado no React

Deve ser uma aplicação em Vite + React similar a aplicação 2, porém agora os botões devem ser componentezados. O objetivo é mostrar como o React facilita o gerenciamento de estado.

Além disso, ele deve ter um exemplo de estado global. Dentro desses quadrados, deve haver um número agora. Todos os quadrados devem mostrar o mesmo número na tela.
