# Estado de uma aplicação HTML & JS

Deve conter uma página HTML simples com um vários botões. Quando pressiono um botão, ele deve mostrar um quadrado na tela ao lado desse botão. O comportamento deve ser feito em JS.

Para demonstrar o estado global em ação, todos os quadrados devem mostrar o mesmo número dentro de si e deve haver um botão de contador que atualiza o número.
